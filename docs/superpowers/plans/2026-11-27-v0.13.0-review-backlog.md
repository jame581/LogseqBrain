# v0.13.0 Review Backlog

Input for the v0.13.0 spec and plan. It comes from two independent read-only reviews of v0.12.2 on 2026-11-27: one of the helper (`bin/brain`, `lib/*.awk`) and one of the skill prose. The safety fixes shipped in v0.12.2 are listed at the end for reference. Everything else is here, ranked within each group.

Items that change skill behavior need an eval run before release (`evals/README.md`). Helper items need a `tests/cases/` case each, and CI on mawk, BWK awk and gawk.

## Skills: behavior gaps (important)

- [ ] **S5. The no-digest fallback is project-shaped only.** `skills/brain-load/SKILL.md:31,45-47` hard-codes `Projects___<Name>.md`, Overview, Current Plan and Session Log. A task page with only `## Notes` makes `brain load` print `digest: missing` and send the model to reads that exit 2. Add a task-page branch: read the largest one or two sections from the section table (`brain read`, or `brain tail --max 8192`).
- [ ] **S6. Actions the prose offers but no skill performs.**
  - "mark it paused" (`brain-load/SKILL.md:29`, `_shared/staleness.md:10`): brain-load is read-only, and brain-save has no project `status::` step. Add a one-line status-change path to brain-save.
  - Creating a task page (`brain-save/SKILL.md:35`): `brain-init/references/templates.md:55` says there is no template. Add a minimal task-page shape.
  - Rotation (`brain-save/references/rotation.md`) has no trigger phrase ("rotate session log") in any description.
  - "search brain for X" and "find X in brain" (`brain-load/references/search.md:3`) are missing from brain-load's description.
- [ ] **S7. "load brain" promises data it never reads.** `brain-load/SKILL.md:57,62`: it reads only Index and Meta, yet says to present "cross-project decisions", which live in `pages/Decisions.md`. It also whole-Reads both pages with no bound or coverage, right above "Never Read a whole page". That line contradicts `_shared/escalation.md:14` (level 5, whole page with consent). Fix:
  - add `brain tail Decisions 'Decision Log' --entries 5 --max 4096`;
  - use `brain read` for Meta's sections;
  - reword line 62 to "…without level-5 consent".
- [ ] **S8. Overly generic triggers.**
  - Bare "summary" (`brain-status/SKILL.md:7`) fires the dashboard on any "give me a summary".
  - "save this", "remember this" and "log this" (`brain-save`) collide with file saves and the host's own memory feature.
  - "brain overview" (status) overlaps "load brain" (load).
  - Fix: qualify them ("brain summary", "remember this in the brain") and give the overview one owner. Measure with the eval trigger cases.

## Helper (minor)

- [ ] **H4. The cap is judged with the stale Map.** `save-finish` (`bin/brain`, the over-cap check) and `map.awk:165` count the old Map line, so a long stale Map plus grown prose is refused although the recomputed Map would fit. Reproduced: "over cap by 167 B", while `digest --apply` then gives 775 B, `map: ok`. Judge the cap on the other bytes plus the computed Map line.
- [ ] **H5. A missing Map is inserted before a child fence.** `map.awk:82-88,188`: when the digest's last bullet owns a fenced block, the new Map line lands before the fence and the block becomes a child of the Map bullet. Let `IP` advance over fenced lines.
- [ ] **H8. A UTF-8 BOM hides the property block.** `core.awk:88,147`: the page reports "digest: not applicable". Strip `\357\273\277` from `L[1]` for matching only.
- [ ] **H9. The write check shares the writer's reader.** A lossy read (BWK awk truncating at NUL, `\r` dropped) is invisible to `onechange.awk`. Add a byte-level check, for example new size = old size + expected delta.
- [ ] **H10. Numeric arguments are not validated.** `--context -3` prints inverted ranges (`search.awk:53`); a non-numeric `--max` becomes 0. Validate digits with `case`.
- [ ] **Suggestions.**
  - `ls pages/*.md … 2>/dev/null` hides an argument-list overflow on large graphs; use `find` or a `for` loop.
  - `json_get` matches the first `"graphPath"` substring anywhere and does not decode `\uXXXX`.
  - Sweep stale `run.*` and `rollback.*` files older than a day.
  - On case-insensitive filesystems, `brain load projects/dig` resolves the file but gets "not applicable"; normalize `PAGE_REL` to the on-disk name.
- [ ] **Test gaps.**
  - No test of the INT/TERM restore in `cleanup`.
  - No BOM page or NUL bytes.
  - No digest with a trailing fence.
  - No "stale long Map plus grown prose" cap case.
